# Data discovery and management tool -- **_datadiscoverer_**
This is the repository for the Data discovery and management tool '*datadiscoverer*' for the data produced by the applications(Apps) based on the GSV available from the ESM simulations done  at different HPC centers.
Please find below the instructions for installation and usage.

+  Clone the repository:
        ```git clone git@github.com:DestinE-Climate-DT/DataDiscoveryAndManagementTool.git``` 
        
* Create a conda environment (here named as 'datadiscovererenv') with the dependencies using the conda_datadiscoverer.txt file in the repository.
   ```conda env create --file conda_datadiscoverer.xt -n datadiscovererenv```
  
+ Register the newly create conda environment 'datadiscovererenv' to the Jupyter.
   ```python -m ipykernel install --user --name datadiscovererenv --display-name=" datadiscovererenv "
     'python' is the appriopriate python version, 'datadiscovererenv' is the conda environment name and also  is the name that is to be displayed ( one could choose a different name also )
      on the Jupyter interface.
   
+ Now this environment will be accessible in the Jupyter interface, in the list of available environments (top right corner dropdown menu, with the display name chosen in the previous step).
   
* Set appropriate values to the variables in the 'configuration.json' under '*datadiscoverer*',which includes the location of the 
   '*datadiscoverer*', location of 'data' produced by the apps, 'output' location for storing the catalogs that will be generated by
   '*datadiscoverer*' among others.

* To create the catalogs using 'datadiscoverer' please execute the following Jupyter notebooks under 'examples'.Please 
   update the path of '*datadiscoverer*' location in the notebooks, so that it is inserted into PATH at runtime.
   
    *intakeCuratorUseCase.ipynb* --- for creating intake catalog
  
    *stacCuratorUseCase.ipynb* --- for creating the STAC catalog

* For using the catalogs generated by 'datadiscoverer' as in the previous step, please execute the following Jupyter notebooks under 
   'examples'.         

    *intakeGUIUser.ipynb* --- for using the intake catalog in GUI mode
  
    *intakeLibUser.ipynb* --- for using the intake catalog in API mode
        
    *STACClientUser.ipynb* --- for using the STAC catalog in API mode

    Follow the instructions under https://github.com/radiantearth/stac-browser for using the STAC catalog with STAC browser.
        
* Documentation about the '*datadiscoverer*' APIs  used in the above notebooks can be found under 'docs'.
   The documentation is available in PDF and HTML versions.

* The sample output catalogs produced by '*datadiscoverer*' are provided under 'output'.
