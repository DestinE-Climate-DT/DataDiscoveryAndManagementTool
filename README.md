# Data discovery and management tool -- **_appdataexplorer_**
This is the repository for the Data discovery and management tool '*appdataexplorer*' for the data produced by the applications(Apps) based on the GSV available from the ESM simulations done  at different HPC centers.
Please find below the instructions for installation and usage.

*  Clone the repository:
        ```git clone git@github.com:DestinE-Climate-DT/DataDiscoveryAndManagementTool.git``` 
        
* Create a conda environment (here named as 'appdataexplorerenv') with the dependencies using the conda_appdataexplorer.txt file in the repository.
   ```conda env create --file conda_appdataexplorer.xt -n appdataexplorerenv``` 
 
  
+ Register the newly create conda environment 'appdataexplorerenv' to the Jupyter.
   ```python -m ipykernel install --user --name appdataexplorerenv --display-name=" appdataexplorerenv " ```
  
  where 'python' is the appriopriate python version,
        'appdataexplorerenv' is the conda environment name and also is the name that is to be displayed in the Jupyter interface ( one could even choose a different display name by
        changing the value set to 'display-name' parameter in the above command ).
   
* Now this environment will be accessible in the Jupyter interface, in the list of available kernels.
   'Kernel' menu -> 'Change Kernel' sub-menu -> 'Select Kernel' dropdown list,
    with the 'display-name' chosen in the previous step.
   
* Set appropriate values to the variables in the 'onfiguration.json' under '*appdataexplorer*',which includes the location of the 
   '*appdataexplorer*', location of 'data' produced by the apps, 'output' location for storing the catalogs that will be generated by
   '*appdataexplorer*' among others.

* To create the catalogs using 'appdataexplorer' please execute the following Jupyter notebooks under 'examples'.Please 
   update the path of '*appdataexplorer*' location in the notebooks, so that it is inserted into PATH at runtime.
   
    *intakeCuratorUseCase.ipynb* --- for creating intake catalog
  
    *stacCuratorUseCase.ipynb* --- for creating the STAC catalog

* For using the catalogs generated by 'appdataexplorer' as in the previous step, please execute the following Jupyter notebooks under 
   'examples'.         

    *intakeGUIUser.ipynb* --- for using the intake catalog in GUI mode
  
    *intakeLibUser.ipynb* --- for using the intake catalog in API mode
        
    *STACClientUser.ipynb* --- for using the STAC catalog in API mode

    Follow the instructions under https://github.com/radiantearth/stac-browser for using the STAC catalog with STAC browser.
        
* Documentation about the '*appdataexplorer*' APIs  used in the above notebooks can be found under 'docs'.
   The documentation is available in PDF and HTML versions.

* The sample output catalogs produced by '*appdataexplorer*' are provided under 'output'.
