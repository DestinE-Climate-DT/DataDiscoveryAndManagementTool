# Data discovery and management tool -- **_datadiscoverer_**
* This is the repository for the Data discovery and management tool 'datadiscoverer' for the data produced by the applications(Apps) based on the GSV available from the ESM simulations done  at different HPC centers.

* The repository is arranged as:
  +  ReadMe.md
  +  conda_DDMT.txt
      + The runtime environment needed for using this package with all the dependencies is provided in conda_DDMT.txt.
  +  /datadiscoverer
      + The package is available under datadiscoverer and could be installed into local python installation or the location of thepackage can be inserted into the system path at runtime.  
  +  /examples
      + The usage of the package is demonstrated in the notebooks provided under examples.  
  +  /docs
      + The API documentation is provided under docs in html and pdf formats with the 'ReadTheDocs' theme.  
  +  /output
      + The sample output catalogs are provided under output.
